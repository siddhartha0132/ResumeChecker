Key Files (⭐⭐⭐ = Critical):
================================

1. app/main.py
   - FastAPI application
   - API endpoints
   - CORS configuration
   - Health checks

2. app/core/extractors/hybrid_extractor.py ⭐⭐⭐
   - Ensemble skill extraction
   - 3 methods: Regex (30%) + spaCy (50%) + Vocabulary (20%)
   - Weighted voting algorithm
   - 92%+ accuracy

3. app/core/scorers/ensemble_scorer.py ⭐⭐⭐
   - Ensemble scoring
   - 3 tiers: Gemini (60%) + TF-IDF (30%) + Rules (10%)
   - Graceful degradation
   - 85%+ accuracy

4. app/services/pdf_service.py ⭐⭐⭐
   - Hybrid PDF parsing
   - 4 methods: pdfplumber → PyPDF2 → pdfminer3 → OCR
   - Automatic fallback
   - 97%+ success rate

5. app/config/settings.py
   - Environment configuration
   - Ensemble weights
   - API keys
   - Performance tuning

6. app/config/constants.py
   - 1000+ skill vocabulary
   - Skill weights (EV domain)
   - Validation patterns
   - Fake data detection


API Endpoints:
==============

GET  /                          - System information
GET  /health                    - Health check
POST /api/parse-resume          - Parse single resume
POST /api/score-resume          - Score single resume
POST /api/batch-score           - Score multiple resumes (up to 100)
GET  /api/skills/vocabulary     - Get skill vocabulary
POST /api/skills/extract        - Extract skills from text

Quick Start:
============

1. Install dependencies:
   pip install -r requirements/dev.txt
   brew install tesseract poppler
   python -m spacy download en_core_web_sm

2. Configure:
   cp .env.example .env
   # Add GEMINI_API_KEY to .env

3. Test installation:
   python scripts/test_installation.py

4. Run server:
   python -m app.main

5. Visit:
   http://localhost:8000/docs
